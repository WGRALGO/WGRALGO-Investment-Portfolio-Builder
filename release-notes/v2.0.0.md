# Investment Portfolio Builder v2.0.0

Works on phones and tablets, in portrait and landscape. Like earlier versions, it works offline, with no ads, analytics, trackers, or account.

## What's new
- **🎢 Market Rollercoaster game:** invest $200 a month from 25 to 65 and make real decisions through crashes, hot tips, fees, and raises. See how you did against Steady Sam and Diversified Dana.
- **🧮 My Investing Plan calculator:** your own numbers, with employer match, fees, and yearly raises. See bad-luck, typical, and good-luck outcomes, in today's dollars too.
- **Looks like a real app:** black launch screen with the big logo, new launcher icon, solid app bar, and About / Privacy / Credits panels.
- **Back button works:** returns from the planner to the game, asks before quitting a game, returns to the start from results, and asks before exiting.
- **Phones and tablets, portrait and landscape:** the app rotates freely, and the start screen fits landscape phones.
- The APK is now named `WGRALGO-InvestmentPortfolioBuilder-v2.0.0.apk`, like every WGRALGO app.
- Still **100% offline**: no internet permission.

## Important: uninstall v1.0.0 first

This release is signed with a new key, so it can't install over v1.0.0. Uninstall the old app first. The app saves nothing, so nothing is lost.
