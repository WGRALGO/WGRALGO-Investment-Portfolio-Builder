# WGRALGO Investment Portfolio Builder — v1.0.0

First official public GitHub release of the WGRALGO Investment Portfolio Builder Android APK.

## What's new

- Offline investment portfolio projection tool with eight portfolio styles
- Year-by-year growth table with inflation-adjusted (real) balance column
- Nominal vs. real growth chart and contribution baseline
- Educational portfolio explanations and per-result money lesson
- Plain-text share/copy summary
- WGRALGO black-and-gold UI, phone and tablet responsive
- Proper release signing
- No `INTERNET` permission requested
- GPLv3 licensing, privacy statement, contributors file, security policy, and README

## Install

1. Download `WGRALGO_Investment_Portfolio_Builder_v1.0.0.apk` from this release.
2. (Optional) verify:
   ```
   sha256sum -c WGRALGO_Investment_Portfolio_Builder_v1.0.0.apk.sha256
   ```
3. Allow install from unknown sources for your browser/file manager.
4. Open the APK and install.

If you previously installed any test/debug build, uninstall it first before installing v1.0.0.
